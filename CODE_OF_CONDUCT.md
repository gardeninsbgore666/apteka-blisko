# Kodeks postępowania

> **Dokument:** PBL-DOC-003 · **Wersja:** 1.0 · **Autor:** Zespół projektowy · **Data:** 2026-11-18

Chcemy, aby projekt był otwarty i przyjazny. Traktuj innych z szacunkiem, krytykuj pomysły bez atakowania osób, przyjmuj konstruktywne uwagi i dbaj o dostępność komunikacji.

Niedopuszczalne są nękanie, dyskryminacja, groźby, obraźliwe komentarze i publikowanie cudzych danych prywatnych. Zgłoszenia naruszeń kieruj do opiekunów repozytorium przez prywatny kanał kontaktowy wskazany w profilu projektu. Opiekunowie rozpatrują je poufnie i mogą poprosić o usunięcie treści lub ograniczyć udział w projekcie.
