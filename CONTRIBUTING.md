# Wkład w projekt

> **Dokument:** PBL-DOC-002 · **Wersja:** 1.0 · **Autor:** Zespół projektowy · **Data:** 2026-11-18

1. Zgłoś błąd przez formularz **Bug report** albo zaproponuj funkcję przez **Feature request**.
2. Opisz kroki odtworzenia, oczekiwane działanie i przeglądarkę. Nie dołączaj danych osobowych ani kopii pełnego rejestru.
3. Zmiany w kodzie kieruj jako pull request do gałęzi głównej. Dodaj lub zaktualizuj testy i opisz, jak ręcznie sprawdzić interfejs.
4. Przed wysłaniem uruchom `npm test` i `npm run lint`.
5. Nie dodawaj pełnych danych rejestrowych, sekretów ani plików `.env` do repozytorium.

Przyjmując zmianę, autorzy mogą ją poprawić, poprosić o doprecyzowanie lub odrzucić z uzasadnieniem. Wszystkich obowiązuje `CODE_OF_CONDUCT.md`.
